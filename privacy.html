Privacy Policy

Last updated: October 14, 2026

Gentle Cat Music Automation is a channel-management application for the Gentle Cat Music YouTube channel. For privacy questions or requests, contact gentle.cat.music.tv@gmail.com.

Information accessed

With the channel owner's authorization, the application uses YouTube Data API v3 to access the authenticated channel's identity, video IDs, titles and publication status, and published comment threads. Comment information processed may include comment IDs, text, commenter display names and channel IDs, associated video IDs, and existing replies. Google OAuth credentials authorize YouTube API operations.

How we use this information

The application checks when videos are public, posts channel comments, reviews published viewer comments, identifies potential spam, places selected comments on hold for review, and posts replies. It checks previous replies and keeps processing history to reduce duplicate responses. Simple positive comments may receive predefined replies.

AI-assisted replies

For some comments, the application sends the comment text and associated video title to Google's Gemini API to help determine whether to reply, ignore, or hold a comment for review, and to draft a relevant reply. Not every comment is sent to Gemini. Google's services process information under their applicable terms and privacy notices.

Data stored

The application uses a local or configured execution-environment JSON history file that can contain comment IDs, video IDs, commenter display names, comment text, reply text, processing decisions, and timestamps. A metadata CSV stores video identifiers and comment-posting status. Execution logs may also contain comment excerpts and operational errors. OAuth credentials and API keys are provided through the execution environment. These files and logs are not part of this public website.

Retention and deletion

Processing history and operational records remain in the configured environment until removed by the operator or according to the hosting platform's retention settings. No fixed automatic deletion period is established by the reviewed script. To request a review or deletion of records controlled by the operator, contact gentle.cat.music.tv@gmail.com. Deleting application records does not automatically remove comments already published on YouTube.

Sharing and security

Data is exchanged with Google YouTube APIs and, for selected comments, Google's Gemini API to provide the functions described above. This application is not designed to sell personal information or use YouTube API data for advertising. Access to the channel is authorized using Google OAuth. The channel owner can revoke the application's access through their Google Account permissions.

Google API Services User Data Policy

Use of information received from Google APIs is subject to the Google API Services User Data Policy, including the Limited Use requirements where applicable.
