Gentle Cat Music Automation

Gentle Cat Music Automation is a channel-management application for the Gentle Cat Music YouTube channel. It helps the channel owner manage YouTube comments, filter inappropriate comments, and prepare AI-assisted replies using Gemini.

Authorized access to YouTube is requested through Google OAuth. This application is intended for use by the channel owner, not as a public comment-management service.
